## 1. Learning Objectives & Observable Skills

Upon completing this learning module, the student will be able to:
- Determine opposite faces on standard and ordinary dice from multiple views
- solve painted large cube cutting problems (faces with 3, 2, 1, 0 colors)
- fold 2D unfolded nets into 3D cubes.

---

## 2. Core Concepts & Required Coverage

The educational resource must provide clear, step-by-step theoretical exposition and practical application for:
- Standard dice (opposite sum = 7) vs General dice
- Common face rule (rotate clockwise from common number)
- Painted cube formulas for n cuts per edge: 3-face = 8 (corners), 2-face = 12(n-2) (edges), 1-face = 6(n-2)^2 (faces), 0-face = (n-2)^3 (interior).
